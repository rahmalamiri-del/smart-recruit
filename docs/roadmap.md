# Roadmap

## Mois 1: Conception et état de l'art

- Comparer TF-IDF, Word2Vec, BERT et CamemBERT.
- Formaliser les cas d'utilisation, classes, séquences.
- Définir les métriques: précision du ranking, temps de réponse, explicabilité.

## Mois 2: Socle web Laravel

- Authentification multi-rôles.
- CRUD profils, offres, candidatures.
- Upload CV et stockage sécurisé.

## Mois 3: Microservice IA

- Parser PDF robuste.
- Extraction compétences, diplôme, expérience.
- API REST `/parse-cv` et `/match`.

## Mois 4: Intégration et tests

- Connexion Laravel vers Python.
- Persistance des scores.
- Tests de performance et cas de faux négatifs.

## Mois 5: Mémoire et finalisation

- Analyse comparative des modèles.
- Captures d'écran, diagrammes, jeux de tests.
- Préparation soutenance.
